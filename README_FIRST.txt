X Space Translator

【初めて使う方】

1. このZIPを右クリックして「すべて展開」
2. 展開したフォルダを開く
3. setup.bat をダブルクリック
4. セットアップ完了まで待つ
5. start.bat をダブルクリック
6. ブラウザが開いたらX Space URLを貼り付ける
7. 文字起こしを開始

次回からは start.bat だけでOKです。

※ setup.batで「ファイル名または拡張子が長すぎます」や
WinError 206が表示された場合は、展開したフォルダを
C:\XSpaceTranslator のような短い場所へ移して、もう一度実行してください。

【Windowsの警告が表示された場合】

ファイル名が setup.bat または start.bat であることと、
公式GitHub ReleaseからダウンロードしたZIPであることを確認してください。
配布元を確認できた場合だけ、Windowsの画面に従って続行してください。
少しでも不明な点がある場合は実行せず、ファイルを削除して
公式Releaseからもう一度ダウンロードしてください。

公式Release:
https://github.com/noboru59631/x-space-translator/releases
